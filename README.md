# 中国旅行攻略自动规划 Skill V2

这个 Skill 将本次南京与新疆策划中有效的做法压缩成可复用流程：三平台分工、官方校验、统一 POI、单向路线、休息点、餐厅嵌入、住宿后置、完整预算、风险切换和多格式交付。

## 安装

克隆仓库后，将整个目录复制到 Codex 的个人技能目录：

```bash
git clone https://github.com/qianxudong8-png/china-trip-planner.git
cp -R china-trip-planner ~/.codex/skills/china-trip-planner
```

重新打开 Codex 后，可通过 `$china-trip-planner` 显式调用，也支持符合用途的自然语言请求自动触发。

## 以后怎么使用

直接说：

> 使用 $china-trip-planner，帮我规划从南京出发、2 人、总预算 10000 元的新疆旅行。时间未定，偏好人文和自然，希望大环线少走回头路，输出完整攻略和 PPT。

建议一次提供：

- 目的地或想覆盖的城市；
- 日期、季节或可接受时段；
- 人数和出发地；
- 总预算或人均预算，以及是否包含往返大交通；
- MUST GO / MUST EAT；
- 兴趣、节奏、步行或驾驶限制；
- 自驾、包车、公共交通等偏好；
- 希望交付攻略、PPT、表格、DOCX 或 PDF。

信息不完整时，Skill 会用显式默认值先推进；只有缺失值会改变路线是否可执行时才询问。

## 四种工作模式

1. 新规划：从需求、调研、验证到成稿完整执行。
2. 修改：添加城市、删景点、改天数或改预算时，复用已验证信息并重算路线和全量预算。
3. 更新：出发前重新检查天气、预约、营业、酒店价格、道路和交通。
4. 演示：路线稳定后生成 PPT，并加入路线图、休息点、餐厅评价、住宿与预算。

## 固定的数据文件

每个目的地保存：

- `trip-input.json`：用户条件和假设；
- `poi-ledger.json`：小红书、大众点评、高德和官方信息；
- `plan.json`：可审计的每日时间表与预算。

初始化示例：

```bash
python3 scripts/init_trip.py 新疆-2027夏季 --destination 新疆 --days 12 --people 2 --budget-per-person 5000 --origin 南京
```

校验示例：

```bash
python3 scripts/audit_plan.py 新疆-2027夏季/plan.json
```

## 质量底线

- 小红书只负责发现与真实体验线索；
- 大众点评负责餐厅分店、评分、人均、菜品和近期口碑；
- 高德负责 POI、入口、距离、路线和时间；
- 官方渠道负责开放、预约、门票、闭馆、道路和临时公告；
- 未查到的信息写 `【待确认】`，不编造；
- 长途路线明确休息、补给和夜间驾驶限制；
- 改路线后重算所有受影响费用；
- PPT 中 ImageGen 图片仅作氛围装饰，不能冒充真实现场。
